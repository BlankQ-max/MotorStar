ℹ️ About This System

🏍️ MotorStar Inventory System

Version: 1.0.0

Course: IAS101 / CC105

Project Type: Web-Based Inventory Management System

Developed For: MotorStar Motorcycle Store

📋 System Features (7 Modules)

  1. Dashboard — Overview of total stock, models, and alerts
  2. Inventory Management — Add, Edit, Delete, View motorcycle records
  3. Sales Transactions — Record sales, auto-calculate totals, deduct stock
  4. Reports — Full inventory list, low-stock alerts, sales summary
  5. Settings — View account info, change password securely
  6. About — System information and user guide
  7. Login / Logout — Secure authentication with Firebase

🛠️ Technology Stack

  • Frontend: Pure HTML, CSS, JavaScript
  • Backend & Database: Firebase (Authentication + Firestore)
  • Design: Fully Mobile Responsive — Ready for MIT App Inventor

📖 Quick User Guide

  • Log in using your assigned inventory manager account
  • Go to Inventory → Click "+ Add New Motorcycle" to stock items
  • Go to Sales → Select model, enter quantity → Save Sale → Stock auto-updates
  • Go to Reports → View full inventory, low-stock items, and sales totals
  • Change password anytime in Settings
